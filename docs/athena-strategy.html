Advantages

Designed to explain and preserve.

  • Read-only onboarding limits upstream write authority.
  • Versioned provenance and deterministic policy support reproducible review.
  • Tenant isolation and append-only evidence add protective layers.
  • Portable reports; optional graph and AI providers.
Disadvantages

The last mile is still unfinished.

  • Partial permission semantics and no activity feeds in current collector manifests.
  • Missing usage can be scored as stale; core inventories lack page navigation.
  • Manual setup and an incomplete fulfillment lifecycle.
  • Recovery, operational ownership, and production proof remain open.

Conditional threat · ownership gap observed

A valid session can still be dangerous.

Prerequisite and impact

An attacker obtains a reviewer/admin session. They could read sensitive evidence or steer decisions within that account’s authority.

Already in Athena

Signed OIDC tokens, issuer/audience/age checks, tenant membership, roles, review-owner checks, and recorded decisions.

What is missing or unproven

Ownership is a username string. The inspected assignment path does not require independent assignment; ordinary reviewer MFA strength is not checked like break-glass authentication.

Next defensive action

Use stable subject IDs and eligible-owner lookup. Verify phishing-resistant IdP policy and require independent review for sensitive cases.

Validate with synthetic users: renamed owner, departed reviewer, wrong role, expired session, and required self-review denial.

Maintenance is part of the product

Continuously

Watch source lag, policy errors, old reviews, pending executions, budget saturation, and tenant-boundary rejections. Give alerts an owner.

Every release

Verify source and deployed policy behavior, PostgreSQL isolation, dependency/image evidence, and the signed-in journey. Match tested and running image digests.

On a planned cadence

Review connector/API changes and disputed findings. Rehearse backups and credential rotation against approved recovery goals; retain the results.
